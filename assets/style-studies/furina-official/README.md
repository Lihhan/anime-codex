`style-preview.png` is a NEW AI-generated full-body style study, not official artwork. Built-in imagegen, official sheet as image reference. Four expressions: attentive, smug, worried, laughing. Not installed in the desktop application, not an animation atlas.

Prompt specification: closely follow first-row Furina stickers' flat 2D graphic language; 2x2 fullbody study, ~2.5 heads tall, white hair and single pale-blue swoosh, navy hat and tailcoat, blue eyes. Clean charcoal outlines, predominantly flat fills, one hard-edged shadow per material, broad pale facial areas, few large hair clumps, restrained highlights. Change eyebrows, eyelids, mouth and body gestures per emotion. Avoid 3D figurine appearance, volumetric lighting, ornate added details, swollen cheeks and glossy doll eyes. Transparent background, no text or logos.

Remaining visual differences: full-body extension is generated rather than directly available in the four official half-body stickers; generated legs and costume details still need style review before making a complete motion set.
