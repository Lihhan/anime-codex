# Activity transition artwork and timing

The Furina sticker pack covers idle/read/meal/gaming/office/sleep/walk/pet/attention: 72 directed combinations. The sleep/read atlas covers those dedicated transitions; activity-bridges-v1.png and social-bridges-v1.png add 32 poses, each a transparent 1254 × 1254, 4 × 4 sheet. Entry/exit actions reuse forward/reverse playback. New character production specifies seven sheets/112 frames.

Both bridge sheets were created with the built-in image generator using public/characters/furina/sticker/life.png as reference; generated pixels were not repainted. Transparent coverage is 65.2% and 64.0%. These are generated key poses: structural coverage does not establish polished anatomy, prop placement or scale consistency.

## Playback and calibration

Transition keyframes last at least 280 ms, with 60 ms added to the first and 100 ms to the last. A typical four-frame segment lasts about 1280 ms; exit plus entry is about 2.56 seconds. Running-loop timing is unchanged.

scripts/calibrate-furina-sprites.cjs reads alpha bounds and writes offsetX, offsetY and renderScale metadata without editing PNGs. Calibration covers 115 referenced cells, aligning foreground centers and foot baselines for stationary actions. Sleep/game loops are scaled toward transition size; running and suspended dragging keep their own anchors. Coordinate correction cannot remove differences in anatomy, hands or prop design, which still need artwork refinement.

## Verification scope

tests/pet-transitions.test.mjs checks 72 routes, frames and aliases for Furina and production contracts. scripts/smoke-all-transitions.mjs clicks 56 directed routes among eight manually selectable activities in Electron and checks transition clips/latest-target queuing. Listening is triggered by system state and covered by static route checks. Version-specific results belong in VALIDATION.md.
